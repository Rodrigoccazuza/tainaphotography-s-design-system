# Tainá Borges Photography Design System

Responsive brand and interface documentation for Tainá Borges Photography.

## Included

- Four official logo compositions
- Brand principles and usage rules
- Color, typography, spacing, layout, and motion tokens
- Photography direction and preferred image ratios
- UI components with English and Portuguese examples
- Accessibility and implementation guidance

## Local preview

Run a static server from the repository root, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
