01 / Foundation

A photography system with editorial restraint.

The brand should feel grounded, warm, observant, intimate and confident. Photography stays primary. Type and interface provide structure rather than competing with the images.

GroundedWarmObservantIntimateConfident
The brand does

Use specificity.

Let real New York locations, available light, people, movement and authentic skin tones create atmosphere. Use strong hierarchy while keeping supporting copy calm.

The brand avoids

Generic luxury.

Avoid heavy presets, overly promotional copy, rounded hero crops, decorative motion, crowded compositions and visual effects that overpower photography.

02 / Logos

Four lockups, paired with the right surface.

The system uses extended and horizontal compositions in light and dark applications. The camera symbol is a fixed brand asset and must not be replaced by a generic icon.

Clear space

Keep at least one logo-circle diameter around the complete lockup.

Minimum width

180 px horizontal; 240 px extended for digital use.

Do not

Stretch, recolor individual elements, add shadows or place the mark on visually noisy crops.

07 / Applications

One system, adapted to the channel.

Do not simply resize. Preserve hierarchy, photography priority and brand restraint while changing the composition for each format.

Website

Editorial, immersive, responsive.

Use generous dark and light sections, strong Poppins display hierarchy, location-led photography, accessible controls and restrained motion.

Instagram

Image first.

Prefer 4:5 photography, concise supporting text, minimal graphic overlays and the approved logo variant for the image background.

Proposals

Calm documentation.

Use light editorial surfaces, dark logo lockups, readable Inter body copy and clear service/pricing hierarchy.

BRAND FOUNDATION
- Brand: Tainá Borges Photography.
- Positioning: natural, location-led photography centered on people, place, atmosphere, and New York specificity.
- Observed audience: travelers, couples, families, portrait clients, proposals, personal sessions, and people wanting an authentic visual record of New York.
- Visual personality: grounded, warm, observant, intimate, confident.
- Do: keep photography primary; use real NYC specificity; preserve authentic warmth and skin tone; combine strong display type with calm supporting copy; use generous spacing; write direct, sensory copy; adapt the same hierarchy to each channel.
- Avoid: generic luxury language; heavy desaturation; generic presets; crowded layouts; decorative motion; rounded hero crops; drop shadows on photography; noisy logo placement; replacing the camera mark with a generic icon.

CONFIRMED VISUAL TOKENS
- Core dark / Asphalt: #161513.
- Core light / Limestone: #E8E2D4.
- Elevated paper: #F4EFE5.
- Highest light / Chalk: #FBF8F1.
- Taxi yellow: #DEA61F.
- Brown token: #7E4834.
- Logo-file brown: #874C38.
- Brick: #A8552B.
- Terracotta: #C75A4A.
- Park: #4D5A2D.
- Steel: #7E8B9E.
- IMPORTANT: #7E4834 and #874C38 are both present in the current system. Do not silently merge them. Use #874C38 for the documented logo disc and mark the general brown-token role for review when relevant.
- Display: Poppins 900 / Black.
- Body and interface: Inter 300–600.
- Technical labels and metadata: JetBrains Mono 400–500.
- Desktop type references: Display 128, H1 72, H2 44, Body 16, Label 11.
- Mobile display sizes currently use responsive CSS clamps. A complete fixed mobile type scale is not formally approved.
- Spacing scale: 4, 8, 16, 24, 48, 96, 128 px.
- Corner radius: 0–4 px default in the documented interface system.
- Grid: flexible 12-column desktop logic with generous page gutters and a central readable content area.
- Preferred image ratios: 4:5 portrait, 3:2 landscape, 1:1 selective, 16:9 hero only.

LOGO SYSTEM
- 01 Extended / light: T + B + camera above the light wordmark; use on asphalt, black, or protected dark photography.
- 02 Horizontal / light: T + B + camera + light wordmark; use for dark navigation and landscape placements.
- 03 Extended / dark: dark wordmark composition for light editorial surfaces.
- 04 Horizontal / dark: dark horizontal composition for light navigation and documents.
- Preserve at least one logo-circle diameter of clear space.
- Minimum digital width: 180 px horizontal, 240 px extended.
- Do not stretch, recolor individual elements, add shadows, rebuild the camera symbol, or place the mark on visually noisy photography.

PHOTOGRAPHY DIRECTION
- Photography is the primary atmospheric layer.
- Prioritize natural, location-led, emotionally unforced images.
- Preserve authentic warmth, skin tone, available light, and recognizable NYC color.
- Curate varied sequences: portraits, couples, families, city, beach, environmental details, and behind-the-camera moments.
- Occasional black-and-white frames may be used for editorial pacing.
- Avoid heavy desaturation, generic presets, excessive smoothing, rounded hero crops, and drop shadows.
- When text overlays photography, use a protection gradient only as needed for readability.

CONTENT VOICE
- English-first documentation with bilingual English / Portuguese interface examples where relevant.
- Voice: direct, observational, intimate, calm, concrete.
- Prefer: “I photograph the small thing nobody else noticed.”
- Avoid inflated language such as “breathtaking timeless works of art.”
- CTA examples: “Book a session,” “See the photographs,” “Send a note.”
- Translate meaning and rhythm rather than word-for-word structure.

MOTION
- Micro interaction: about 180 ms.
- Default state change: about 320 ms.
- Section reveal: about 720 ms.
- Cinematic transition: 900–1200 ms.
- Scroll reveals use soft fade / translate movement with restrained staggering.
- The approved entry preloader uses a New York brownstone brick wall that dismantles to reveal the site.
- Respect prefers-reduced-motion and remove non-essential motion when requested.
- Avoid bounce, spring, overshoot, or continuous decorative motion.

IMPLEMENTATION METHOD
1. Audit the requested platform, format, dimensions, safe areas, interaction states, export limits, and accessibility needs.
2. Map every visual decision to a confirmed token or rule above.
3. Start with photography and content purpose before adding interface styling.
4. Build hierarchy with Poppins for impact, Inter for reading, and JetBrains Mono only for metadata / technical labels.
5. Keep dark Asphalt and light Limestone as the primary environmental surfaces. Use Taxi Yellow as the signature accent.
6. Use only the confirmed spacing scale. Preserve generous whitespace and a central readable content area.
7. Prevent horizontal overflow at every viewport width.
8. Use the correct logo for its background, including clear space and minimum-size rules.
9. Render actual reusable components when the format supports them: buttons, cards, tags, form fields, navigation, language controls, pricing blocks, lightbox / modal behavior.
10. Adapt the composition to the channel’s purpose rather than merely resizing it.
11. Preserve authentic photography crops and do not cover important faces or subjects with interface content.
12. Mark unsupported channels, missing source files, or unresolved values as [NEEDS DECISION].

- no horizontal overflow;

- contrast, focus, alt text, and reduced motion are checked;
- the brown-token vs logo-brown difference has not been silently reconciled;
- every unknown is labeled [NEEDS DECISION].

09 / Divergences

Variations that require a conscious decision.

These differences already exist in the current repository. They are documented instead of silently normalized.

High

Two brown values

#7E4834 is the general Brown token while #874C38 is used in the logo system.

Medium

Responsive type scale

Desktop reference values are explicit; mobile display sizes are implemented with clamps rather than one approved fixed scale.

Medium

Breakpoints and page gutters

Documentation and implementation have used slightly different breakpoint/gutter references over iterations. Production should choose one canonical set.
