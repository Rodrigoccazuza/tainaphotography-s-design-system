01 / foundation

A photography system with editorial restraint.

The existing system repeatedly describes the brand as grounded, warm, observant, confident, and natural. It uses New York specificity instead of generic luxury cues.

The brand does
+

Let photographs carry atmosphere.

+

Use city-specific details: brick, subway rhythm, parks, coastlines, available light.

+

Pair heavy display type with spacious body copy.

+

Use direct first-person or conversational copy.

The brand avoids
−

Generic luxury language and inflated claims.

−

Heavy presets, aggressive desaturation, decorative shadows, and over-styled hero crops.

−

Changing individual logo colors or rebuilding the camera icon.

Dark surfaces

Light surfaces

07 / applications

How the system becomes a piece in each documented channel.

Only application rules supported by the current repository are stated as rules. Where a channel is referenced but not fully specified, it is marked as unresolved instead of inventing dimensions or templates.

Website

Primary production expression

Dark immersive hero, image-first galleries, bilingual interface examples, taxi-yellow action accents, strong Poppins headings, Inter body copy, thin hairlines, restrained motion, and accessible focus states.

Defined
Instagram

Carry over the same visual grammar

The repository supports portrait-led photography, 4:5 as a preferred ratio, warm color, occasional black-and-white pacing, Poppins display typography, and the existing palette. Exact feed templates, story dimensions, and posting hierarchy are not yet defined in the repository.

Partially defined
Proposals

Use the editorial document language

Light paper or limestone surfaces, dark wordmark, clear hierarchy, Poppins for titles, Inter for long reading, JetBrains Mono for metadata, and hairlines before shadows. Proposal page size and reusable proposal template are not defined.

Partially defined
08 / inconsistencies

Variations that require a conscious decision.

These differences already exist inside the current repository. They are surfaced here rather than silently reconciled.

High

Two brown values

The logo construction uses #874C38 while the general Brown color token is #7E4834. Decide whether these remain intentionally separate or whether one becomes canonical.

Medium

Documented breakpoints differ from implementation breakpoints

The spacing documentation names 720 / 1024, while current CSS also uses 430, 760, 980/1050-style responsive thresholds. A canonical breakpoint set is not yet stated.

Medium

Page margins differ between documentation and mobile implementation

The written layout guidance says 32–42 px page margins. The current mobile fixes reduce the reading area to roughly 20–24 px side gutters on small screens.

Low

Several light neutrals are intentionally close

Limestone #E8E2D4, Paper #F4EFE5, and Chalk #FBF8F1 are all present. Their roles are described, but channel-by-channel usage is not fully governed.

09 / open decisions

What is still missing for the system to become complete.

01

Canonical brown rule

Resolve the relationship between #874C38 in the logo and #7E4834 in the general palette.

02

Canonical breakpoint set

Choose the official responsive thresholds to document and reuse.

03

Instagram templates

Feed, carousel, cover, story, and text-safe-area rules are not defined in the repository.

04

Proposal template

Page dimensions, title-page hierarchy, pricing layout, and approval format are not defined.

05

Full mobile type scale

Only hero-related mobile clamps are explicit. H2, body, caption, and label mobile tokens are not separately defined.

06

Image export specification

The style and preferred ratios are documented, but delivery resolution, compression, and channel-specific exports are not.
